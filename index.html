SQL Toolkit (By Emerson Carlos) ← Início

Seu kit de ferramentas para SQL Server

Formate queries, leia STATISTICS IO/TIME, investigue planos e deadlocks, desparametrize, anonimize e compare o antes/depois do tuning. Tudo em uma página, sem instalar nada.

Privacidade: tudo roda no seu navegador. Nada é enviado para servidor nenhum e nada é guardado: ao fechar ou recarregar a página, o que você colou some. Funciona offline se você salvar este arquivo e abri-lo no computador.

Formatador SQL

Cole uma query bagunçada e receba o T-SQL organizado. Ajuste caixa das palavras-chave, indentação, vírgulas, CASE, IN, BETWEEN, JOINs e mais, ou minifique e colora o resultado.

Opções de estilo 

      

      

        
        
        
        
        
        
      

      
Cobre SELECT / INSERT / UPDATE / DELETE, CTEs, JOINs, subqueries, CASE, IF/BEGIN/END, DECLARE e lotes com GO. Strings e comentários são preservados. Confira o resultado antes de usar em produção.

    

  


  
  

    
Analisador IO / TIME

    
Cole a saída da aba Mensagens do SSMS (com SET STATISTICS IO, TIME ON) e veja os totais e o peso de cada tabela.

    

      
      

        
        
        
      

      
Funciona com a saída em inglês (Table '...'. Scan count ... e CPU time = ... ms). Se houver várias execuções coladas, os valores são somados.

    

    

  


  
  

    
Plano de execução (.sqlplan)

    
Abra um arquivo .sqlplan, arraste-o para a caixa ou cole o XML do plano. A ferramenta lista alertas, índices ausentes e os operadores mais caros.

    

      

      

        
        
        
        
        
      

      
O arquivo é lido localmente pelo navegador. No SSMS: botão direito no plano → “Save Execution Plan As…”. Custos dos operadores são estimativas do otimizador (unidades internas, não segundos).

    

    

  


  
  

    
Deadlock

    
Cole o XML do deadlock graph (xml_deadlock_report, da sessão system_health ou de um arquivo .xdl) e veja quem foi a vítima, quais objetos estavam envolvidos e por que o impasse aconteceu.

    

      

      

        
        
        
        
        
      

    

    

  


  
  

    
Desparametrizador

    
Transforma uma chamada sp_executesql (do Profiler, Extended Events ou Query Store) em uma query pronta para rodar no SSMS, com os DECLARE dos parâmetros.

    

      

      

        

        

      

      

        
        
        
        
      

      

      
Converte a primeira chamada encontrada. Aceita as formas posicional e com @stmt= / @params=.

    

  


  
  

    
Anonimizador

    
Troque nomes de tabelas, colunas, bancos e valores por nomes genéricos antes de compartilhar uma query em post, fórum ou suporte.
